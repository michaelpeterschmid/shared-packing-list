# Features

### To be implemented:

- If a user that is not logged in, he can sign up or log in but not access any other pages.
- A user can sign in with email and password
- A user can join a Group if he has the credentials
- A user can create a group and secure it with a password
- A user can join a group if he has a valid link (unique per group) and knows the password
- Each user in a group can read, create, delete or update list-items.
- The user can use the app offline
